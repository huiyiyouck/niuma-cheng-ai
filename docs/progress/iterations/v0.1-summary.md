## 交付物

### 代码侧
- **内部 registry/dispatch**：tasks.py TaskSpec + register_task / get_task / run_task，news-l1 首个注册项，对外契约不变（AC-9）
- **条件图编排**：ingest_context → route_after_ingest（kb>link>web 优先级）→ llm_process → normalize_output（ADR-0001）
- **ChainedAIClient**：多 provider 链式 fallback（rate_limited / timeout / 5xx / auth / empty / parse_error 均 fallback）+ JSON 修复 + normalize（score clamp / context URL 过滤）+ 显式总 timeout budget（ADR-0002）
- **工具真实化**：
  - link_reader：从 raw_content.url / canonical_url 取 URL 自抓
  - web_search：直连 Tavily API（不经 openclaw 网关）
  - kb：真实调 xiaobao POST /v1/kb-search（CN-002 纳入 v0.1）
- **优雅降级**：部分可用 = status=succeeded + degraded 标记；完全不可用 = failed + output=null + error（AC-6）
- **prompt**：system prompt 明确四维 0-5 + 非空中文 reason + 五类标签 + 中文摘要 + translation.zh + 不编造 URL + 仅输出 JSON
